# 不好，我被迷宫包围了

一款第一人称 3D 恐怖迷宫逃生游戏。每次进入，迷宫都会重新生成——墙壁会变，出口不会主动等你。

你唯一能依靠的是一把挂着战术手电的狙击枪，以及耳边越来越近的脚步声。

## 玩法

1. 在迷宫中寻找**黄铜钥匙**
2. 用钥匙打开尽头的铁门
3. 在它找到你之前逃出去

迷宫中有东西在游荡。它一直在找你，离得越近，屏幕边缘越红。

## 操作

| 按键 | 功能 |
| --- | --- |
| `W A S D` | 移动 |
| 鼠标 | 观察视角（点击画面锁定指针） |
| `Shift` | 冲刺（消耗体力） |
| `E` | 拾取 / 开门 |
| `F` | 开关战术手电 |
| `Esc` | 暂停 |

## 特性

- **程序化迷宫**：递归回溯算法生成 17×17 随机迷宫，配合种子随机数，每一局都不同
- **第一人称狙击枪**：枪身上挂载战术手电，`F` 键控制照明与镜片亮度
- **动态追踪**：敌人实时 BFS 寻路追击，逼近时提速，HUD 与屏幕边缘同步给出威胁警告
- **程序化音频**：不依赖任何音频文件，全部由 Web Audio API 实时合成
  - 低频底盘声 + 不和谐高频颤音 + 次低频脉动构成恐怖氛围
  - 随机触发的远处异响（金属刮擦 / 低频呜咽 / 远处敲击）
  - 玩家脚步声（左右交替声像、走跑节奏差异、踩地低频冲击）
  - 敌人脚步、心跳、呼吸均由空间音频定位
- **探索记录**：小地图实时显示已走过区域

## 技术栈

- [Three.js](https://threejs.org/)：WebGL 渲染、`InstancedMesh` 墙体、SpotLight 阴影
- [Vite](https://vite.dev/)：开发与构建
- Web Audio API / PannerNode（HRTF）：空间化音效与程序化音乐
- Pointer Lock API：鼠标视角控制

## 本地运行

```bash
npm install
npm run dev
```

构建产物：

```bash
npm run build
npm run preview
```

### 局域网访问

`dev` / `preview` 脚本已使用 `vite --host`，监听 `0.0.0.0`。启动后终端会输出 `Network:` 地址，同一局域网内的手机或其它电脑可直接访问（首次启动若系统防火墙弹窗，请选择"允许"）。

游戏建议佩戴耳机，音量会提示很多事。所有音效均为实时合成，首次交互（点击"进入迷宫"）后才会启动音频上下文。
